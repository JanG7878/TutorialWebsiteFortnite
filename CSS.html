Titelblatt HTML-Code CSS

Als erstes haben wir gelernt, dass es 3 Arten gibt um CSS einzubinden, und zwar:

    • Intern (direkt beim Element mit einem style-Tag)
      Extern (in einem CSS stylsheet)
      Inline (direkt im html mit einem style-Attribut)

    so bindet man das extern ein: link rel="stylesheet" type="text/css" href="mystyle.css"

    • Die übliche Variante ist extern, diese macht man mit einem stylesheet.

    als erstes braucht man den selector dann das property und dann das Value

    z.B. h1 {color: red;}

    es gibt verschiedene propertys und values:

    • font-size: 50px (das ist die Textgröße)
      border: 1px (das ist der Rahmen)
      text-shadow: 1px 1px 1px white (das ist ein text schatten)

    • und viele mehr

    Es gibt Klassen und id´s, man macht diese wen man den selector im css schon vergeben hat, aber man etwas anderes machen wil.

    Man mach klassen mit einem "." vor dem selector, und id´s mit einem "#" vor dem Selector.

    Dann gibt es noch die Flexboxen, man macht diese um verschiedene items in die richtige position zu bringen

    man bindet diese so z.b. ein: section { display: flex; flex-direction: row-reverse; }

    aber davor muss man die items die man ändern möchte mit section beschriften.
